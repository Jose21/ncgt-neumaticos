# NCGT — sitio web para GitHub Pages

Sitio estático preparado para publicación gratuita.

## Archivos
- index.html
- neumaticos.html
- servicios.html
- nosotros.html
- contacto.html
- assets/css/styles.css
- assets/js/main.js
- robots.txt
- sitemap.xml

## Pendiente antes de producción
1. Confirmar teléfono, WhatsApp y horario.
2. Agregar fotografías reales en `assets/img/`.
3. Reemplazar `TU-USUARIO` y `TU-REPOSITORIO` en robots.txt y sitemap.xml.
4. Actualizar canonical/OG/JSON-LD cuando tengamos la URL final.
5. Confirmar con NCGT qué servicios ofrece realmente para no publicar información incorrecta.

## Publicación
Crear un repositorio público en GitHub, subir el contenido y activar:
Settings → Pages → Deploy from a branch → main → /(root).
